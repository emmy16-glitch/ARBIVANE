# NEAR HACKATHON delivery checklist

**Event:** November 1–14, 2026. Recheck the official rules and submission time before uploading. This file is an internal checklist, not an organizer-issued HACKATHON.md.

- [ ] Public repository; readable problem statement and install/run steps
- [ ] Description between 20 and 2,000 characters and accurately scoped project/track selections
- [ ] Complete architecture diagram, reproducible evidence and explicit list of NEAR technology **actually** used
- [ ] README demonstrates `npm test`, real final-block reads, testnet contract safety and eventual Intents receipt
- [ ] Public demo on X with video or screenshots; URL saved
- [ ] Submitted lead contact, number of teammates, selected tracks and NEAR payout address
- [ ] Independent judge can follow `Do X -> See Y` steps without owning production keys
- [ ] Clear labels distinguish mocked fixture, testnet demonstration and real mainnet transfer
- [ ] Upstream dependencies and attribution documented; no false originality claims
- [ ] No claim of autonomous profit, zero gas costs, invisible competition, verified TEE or production security without transaction/attestation evidence

The one-team-one-submission rule and November submission deadlines should be reconfirmed from the official website: https://nearhackathon.com/
